# Finance Bot (личный учёт доходов/расходов)

## Запуск
1) Python 3.10+ (желательно 3.11+)
2) Установить зависимости:
   pip install -r requirements.txt
3) Создать .env:
   BOT_TOKEN=...
   (опционально) ALLOWED_USER_ID=...
4) Запуск:
   python bot.py

## Использование
- Отправь сумму: 1500 или 120.50
- Выбери доход/расход
- Выбери категорию — запись сохранится в SQLite

## Отчёты
/day, /week, /month, /year
